À propos d'Edusco

Plateforme de Gestion d'Institut Supérieur

Edusco est une solution web moderne et complète développée pour répondre aux besoins spécifiques de la gestion administrative et pédagogique des instituts supérieurs.

Technologies utilisées :
  • Backend : Flask (Python)
  • Base de données : MySQL / SQLite
  • Frontend : HTML5, CSS3, JavaScript
  • Interface : AdminLTE 3
  • Authentification : Flask-Login
Fonctionnalités :
  • Gestion complète des étudiants et enseignants
  • Administration des unités d'enseignement
  • Saisie de notes avec interface AJAX
  • Gestion des absences et justifications
  • Emplois du temps dynamiques
  • Délibérations et validation d'année
  • Tableaux de bord personnalisés
  • Interface responsive et moderne
