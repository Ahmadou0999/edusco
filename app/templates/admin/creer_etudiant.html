Créer un Étudiant

Remplissez tous les champs obligatoires pour créer un nouvel étudiant. L'étudiant sera automatiquement inscrit dans l'année académique sélectionnée.

Champs obligatoires :
  • Matricule
  • Nom
  • Prénom
  • Date de naissance
  • Sexe
  • Statut
  • Email
  • Année académique
Champs optionnels :
  • Téléphone
  • Adresse
Compte utilisateur automatique

Un compte utilisateur sera créé automatiquement pour permettre à l'étudiant de se connecter avec :

  • Email : L'email saisi
  • Mot de passe : Celui saisi dans le formulaire
